# Sami Areski - Developer Portfolio

A beautiful, modern portfolio website showcasing my projects, built with React, TypeScript, and shadcn/ui.

## 🚀 Live Demo

Visit: [https://efsmert.github.io](https://efsmert.github.io)

## ✨ Features

- **Modern Design**: Red and black theme with glassmorphism effects
- **Responsive**: Works beautifully on all devices
- **Smooth Animations**: Micro-animations and hover effects
- **Project Showcase**: Filterable project cards with categories
- **Skills Section**: Organized skill categories with icons
- **Contact Form**: Easy way to get in touch
- **SEO Optimized**: Meta tags and Open Graph support

## 🛠️ Tech Stack

- **React 19** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS 4** - Styling
- **shadcn/ui** - Component library
- **Bun** - Runtime and bundler
- **Lucide Icons** - Icon system

## 📦 Development

### Prerequisites

- [Bun](https://bun.sh) (latest version)

### Installation

```bash
# Install dependencies
bun install

# Start development server
bun run dev
```

The dev server runs at `http://localhost:3000`

### Building for Production

```bash
bun run build
```

Output is generated in the `dist/` folder.

## 🚢 Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions when pushing to the `main` branch.

### Setting up GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Under "Build and deployment", select "GitHub Actions"
4. Push to `main` branch to trigger deployment

## 📝 Customization

### Projects

Edit `src/data/projects.ts` to add or modify your projects.

### Theme

Modify `styles/globals.css` to adjust colors and design tokens.

### Personal Info

Update your name, links, and content in the component files under `src/components/`.
